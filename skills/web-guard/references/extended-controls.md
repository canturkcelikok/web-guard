## Budget

Accept optional token and monetary limits without requesting API keys. Persist budget.json with configured limits/currency, accounting source, per-phase input/output/cached/reasoning usage when reported, authoritative total, measured cost and checkpoint. Use host-reported totals; avoid double-counting cached/reasoning tokens already included. A model switch/continuation does not reset cumulative run spend. Do not reuse a previous host's counters as current usage unless accounting continuity is verified.

At 80% of an observable limit, summarize remaining work and reduce duplicate narration/discovery. At 100%, save evidence/state and report incomplete checks before initiating another expensive phase; continue after a raised budget or a genuinely cheaper authorized route. Reserve reporting/checkpoint room where host controls permit. A skill cannot enforce an absolute token ceiling if the host does not expose/control tokens. In that case set measurement/enforcement unavailable, keep bounded tool output, and never fabricate consumption or savings. If cost is not reported, calculate only with verified model/version/date pricing and mark it an estimate; currency conversion needs an explicit rate/source. Respect scanner/cloud/SMS/AI spend separately.

## Release gate contract

Run `python3 <skill>/scripts/gate.py --before baseline.json --after final.json --required-control AUTHZ --required-control CHANGE --max-age-hours 24`. Add project-specific required controls; this example is not a universal release policy. Default blocked severities: critical/high. Optionally set --block-severity values explicitly. Exit 0 = selected policy passes, 1 = blocked, 2 = invalid input/tool failure. CI must treat every nonzero exit as a failed gate; validate the exact target/environment/revision/profile against trusted CI context before calling. Protect the result files and CI job from untrusted PRs. The helper validates claims structurally, not scanner honesty, actual deployment or completeness. Keep report-only until activation is authorized. Record job/check names, policy version, result provenance and whether enforced or merely prepared.
